# Cronograma de Entregables - Frontend y Backend

Este documento resume el cronograma del curso enfocado solo en desarrollo movil y backend.
Se omitieron las columnas de informe academico e implementacion IA para usarlo como guia tecnica del proyecto.

## Sesion 08

**Tema / silabo:** SUSTENTACION DEL EXAMEN PARCIAL

**Frontend movil**

Presentar el prototipo móvil desarrollado en Flutter, Kotlin o React Native + Expo, junto con las pantallas en Figma validadas mediante pruebas de usabilidad y accesibilidad. / Implementar un módulo de inicio de sesión con usuario y contraseña, validado mediante una API o endpoint. / Si el acceso es correcto, se mostrará la interfaz principal con Navigation Drawer o menú lateral; caso contrario, el mensaje: “Usuario y clave incorrectos”.

**Backend**

Asimismo, se deberá abarcar la parte del backend, desarrollado preferentemente en Flask, aunque también puede emplearse FastAPI, Django o Spring Boot según el caso. / El backend deberá incluir funcionalidades administrativas, como mantenimiento, gestión de usuarios, permisos u otras funciones pertinentes al proyecto. / Además, deberá integrar un modelo de IA entrenado, parcialmente funcional, desplegado y operativo para ser consumido por el aplicativo móvil.

**Tema / silabo:** Diseño de software móvil I / Arquitectura del software móvil / Patrones de diseño en frontend y backend / Diseño de base de datos con SQLite

**Frontend movil**

**Backend**

Aplicar el patron arquitectonico de software de Preferencia en el desarrollo de la Backend en Flask o en otro framework en un avance del 45% en las funcionalidades administrativas, como mantenimiento, gestión de usuarios, permisos , uso del modelo de IA entrenado y otras funciones pertinentes al proyecto.
